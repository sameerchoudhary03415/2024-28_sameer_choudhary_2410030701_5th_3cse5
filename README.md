## 📌 About the Internship

The internship focused on building a strong practical foundation in cloud computing on **Amazon Web Services (AWS)**, progressing from Cloud Foundations to Cloud Architecting — covering global infrastructure, cloud economics, security, networking, compute, storage, database services, and serverless architecture. It followed a structured, week-wise curriculum combining conceptual learning with weekly assessments and project submissions, culminating in a Final Assessment Test.

**Organization:** EduSkills Academy (ISO 9001:2015 & ISO 20000-1:2018 certified, Great Place to Work certified) — runs the AICTE–EduSkills Virtual Internship Program under the patronage of the **AICTE National Internship Portal**, with curriculum provided by **AWS Academy**.

---

## 🎯 Objectives

- Understand cloud computing concepts, economics, and billing, along with AWS global infrastructure
- Gain practical knowledge of cloud security, networking, and content delivery on AWS
- Learn AWS compute, storage, and database services, along with cloud architecture fundamentals
- Understand automatic scaling and monitoring for optimizing performance and managing resources
- Design cloud architecture using IAM security, Amazon S3, Amazon EC2, Amazon RDS, and Amazon VPC (including VPC peering)
- Implement secure access using IAM and KMS, and configure monitoring, elasticity, and high availability using EC2 and Route 53
- Build decoupled architectures using Amazon SQS and design serverless microservices using AWS Lambda
- Understand data engineering patterns and disaster recovery planning, and prepare for the AWS Certified Solutions Architect – Associate certification
